====================================================
한국어 TTS - 안드로이드 앱 (Android Studio 프로젝트)
====================================================

이 폴더는 컴파일된 .apk 파일이 아니라, Android Studio로 열어서 직접 빌드하는
"소스 프로젝트"입니다. 이 환경(서버/사샌드박스)에는 Java, Android SDK, Gradle
이 설치되어 있지 않아서 .apk 를 직접 만들어 드릴 수 없었습니다 — 대신 바로
빌드 가능한 전체 프로젝트를 작성했습니다.

기능은 데스크톱 버전(../Allinone (2)/tts.py, korean_tts.py)과 완전히 같은
엔진을 코틀린으로 그대로 옮긴 것입니다: 연음화·비음화·유음화·격음화·경음화
처리, 음량 자동 보정, 이중모음/받침 크로스페이드까지 전부 포함됩니다.

핵심 기능: 다른 앱에서 한글 텍스트를 선택하면 나오는 기본 팝업 메뉴
("복사", "웹 검색" 등이 뜨는 그 메뉴)에 "한국어로 읽기" 항목이 추가되어,
탭하면 그 자리에서 바로 읽어주고 원래 앱에서 벗어나지 않습니다.


====================================================
1) 준비물
====================================================
    - Android Studio (무료) - https://developer.android.com/studio
      설치 시 Android SDK 도 함께 설치됩니다. 별도로 SDK를 따로 받을
      필요 없습니다.
    - 실제 기기 (USB 디버깅 켠 안드로이드 8.0 이상) 또는 Android Studio가
      제공하는 에뮬레이터(가상 기기).


====================================================
2) 열기
====================================================
    1. Android Studio 실행 -> "Open" -> 이 폴더(KoreanTTS-Android) 선택.
    2. Gradle 동기화가 끝날 때까지 기다립니다 (처음엔 각종 라이브러리를
       받느라 몇 분 걸릴 수 있습니다. 인터넷 연결 필요).
    3. AGP(Android Gradle Plugin)나 Kotlin 버전을 올리라는 안내가 뜨면
       "Upgrade" 를 눌러도 안전합니다 (이 프로젝트는 최신 버전 기준으로
       작성했지만, Android Studio 버전에 따라 약간 다를 수 있습니다).

Android Studio 없이 터미널/CI에서 빌드하기
    gradlew/gradlew.bat (Gradle wrapper)가 포함되어 있으므로 아래처럼
    직접 빌드할 수도 있습니다 (JDK 17 필요):

        cd KoreanTTS-Android
        ./gradlew assembleDebug          (Windows: gradlew.bat assembleDebug)

    .github/workflows/release.yml 이 바로 이 명령으로 GitHub Actions에서
    자동으로 APK를 빌드합니다 - 자세한 내용은 저장소 루트의
    BUILD_EXE.txt의 "자동 빌드 (GitHub Releases)" 항목 참고.


====================================================
3) 실행/빌드
====================================================
기기에 바로 설치해서 써보기
    화면 위쪽에서 기기를 선택하고 ▶(Run) 버튼을 누르면 빌드 후 자동
    설치·실행됩니다.

.apk 파일 자체가 필요할 때
    메뉴 Build -> Build Bundle(s) / APK(s) -> Build APK(s)
    빌드가 끝나면 알림에 뜨는 "locate" 링크를 클릭하거나
    app/build/outputs/apk/debug/app-debug.apk 에서 찾을 수 있습니다.
    이 파일을 다른 안드로이드 기기로 옮겨 설치할 수 있습니다 (설치 시
    "출처를 알 수 없는 앱" 허용이 필요할 수 있습니다).


====================================================
4) 사용법
====================================================
어디서든 선택한 글자 읽기 (핵심 기능)
    1. 아무 앱(브라우저, 메모, 카카오톡 등)에서 한글 텍스트를 길게 눌러
       선택합니다.
    2. 뜨는 팝업 메뉴에서 "..." 를 눌러 더 보기 -> "한국어로 읽기" 선택.
       (앱마다 메뉴 아이콘이 바로 보이거나 "..."를 한 번 더 눌러야 할
       수 있습니다.)
    3. 화면 전환 없이 그 자리에서 바로 읽어줍니다.

앱을 직접 열어서 쓰기
    앱 아이콘을 눌러 실행 -> 텍스트 입력 -> 재생/정지/발음 보기/WAV로 저장.

재생 속도 조절
    메인 화면의 슬라이더로 0.5배 ~ 2.0배까지 조절합니다. 한 번 설정하면
    앱을 다시 열어도, 다른 앱에서 "한국어로 읽기"로 읽을 때도 계속
    적용됩니다 (기기에 저장되는 설정 하나입니다).

    안드로이드는 AudioTrack의 PlaybackParams 기능을 사용해서 속도를
    바꿔도 목소리 톤(음높이)이 변하지 않습니다 - 데스크톱 tts.py 의
    --speed 는 (외부 라이브러리 없이) 단순 리샘플링 방식이라 속도를
    바꾸면 음높이도 같이 바뀌는 것과 다른 점입니다.

띄어쓰기 간격 조절
    메인 화면의 슬라이더로 0ms ~ 800ms 까지 조절합니다 (기본 300ms).
    문장부호나 띄어쓰기에서 쉬는 길이입니다 - 데스크톱 tts.py 의 --gap 과
    같은 값입니다. 속도와 마찬가지로 한 번 설정하면 "한국어로 읽기"에도
    계속 적용됩니다.

볼륨 조절
    메인 화면의 슬라이더로 0% ~ 100% 까지 조절합니다. 이 앱이 재생하는
    소리에만 적용되는 볼륨이라 휴대폰 전체 미디어 볼륨과는 별개입니다
    (AudioTrack.setVolume 사용). 역시 "한국어로 읽기"에도 계속 적용됩니다.

    이것과 별개로, 음성 조각 자체의 기본 음량도 예전보다 크게(+4dB) 잡혀
    있습니다 - 슬라이더는 100%가 기본값이니, 그래도 작게 들리면 폰 자체의
    미디어 볼륨을 확인해보세요.

받침 ㄱㄷㅂ 뒤 간격 조절
    메인 화면의 슬라이더로 0ms ~ 200ms 까지 조절합니다 (기본 40ms).
    받침 ㄱ/ㄷ/ㅂ(ㅋ,ㄲ,ㅅ,ㅆ,ㅈ,ㅊ,ㅌ,ㅎ,ㅍ 등도 전부 이 셋 중 하나로 발음됨)
    으로 끝나는 글자가 다음 글자로 너무 빨리 넘어가는 문제를 위해 그 사이에
    추가로 넣는 간격입니다. 그 외 받침(ㄴㄹㅁㅇ)이나 받침 없는 글자 사이,
    비음화 등으로 발음이 이미 바뀐 경우에는 적용되지 않습니다 - 데스크톱
    tts.py 의 --stop-gap 과 같은 값이고, "한국어로 읽기"에도 계속
    적용됩니다.

목소리 선택 (여러 목소리를 넣었을 때)
    메인 화면의 드롭다운에서 고릅니다. assets/sound/ 안에 목소리마다 자기
    이름의 폴더가 하나씩 있습니다 (원래 목소리도 assets/sound/default/) -
    자세한 건 ..\Allinone (2)\TTS_README.txt 의 "여러 목소리" 항목과
    sync-sound-assets.bat 참고. 목소리를 하나만 쓰고 있다면 드롭다운에
    'default' 하나만 보이고 신경 쓸 게 없습니다. 다른 목소리 폴더 이름은
    밑줄(_)이나 마침표(.)로 시작하면 안 됩니다 - 안드로이드 빌드 도구가
    그런 이름의 assets 폴더를 자동으로 빼버립니다.

    목소리 폴더 안에 bank.json 이 있으면 그 목소리가 "조각 방식" 말고
    다른 사운드 뱅크 종류(예: 완전한 음절 통째로 녹음 - TTS_README.txt의
    "사운드 뱅크 종류" 항목 참고)일 수 있습니다. 이 앱은 아직 조각 방식만
    재생할 수 있어서, 다른 종류의 목소리는 드롭다운에 나타나지 않습니다
    (오류 없이 조용히 숨겨짐 - sync-sound-assets.bat 으로 파일은 계속
    동기화되니, 나중에 이 앱이 그 방식을 지원하게 되면 다시 동기화할
    필요 없이 바로 나타납니다).


====================================================
5) 알려진 사항
====================================================
    - 처음에는 이 환경에 Java/Gradle이 없어 컴파일 없이 작성했지만,
      이후 Android Studio가 설치한 JDK/SDK/Gradle을 이용해 실제로
      여러 번 clean 빌드까지 성공시켰습니다 (assets/sound 268개 파일도
      apk 안에 정상적으로 들어있는 것까지 확인). 그래도 화면에서 직접
      눌러보고 소리까지 들어보는 테스트는 못 했으니, 실제 기기/에뮬레이터
      에서 한 번 확인해보시는 게 좋습니다.
    - 최소 지원 버전: 안드로이드 8.0 (API 26). 그보다 낮은 기기는
      지원하지 않습니다 (앱 아이콘 리소스 형식 때문- 대신 별도의
      구버전용 아이콘 파일을 만들 필요가 없어졌습니다).
    - "떠다니는 말풍선(플로팅 오버레이)" 방식은 구현하지 않았습니다 -
      대신 안드로이드 기본 텍스트 선택 메뉴에 항목을 추가하는 방식을
      택했습니다. 특별한 권한(다른 앱 위에 표시, 접근성 서비스)이 전혀
      필요 없고, 훨씬 안정적으로 동작합니다. 나중에 재생/일시정지를
      계속 조작할 수 있는 작은 말풍선이 필요하면 추가로 요청해주세요.
    - sound/ 의 음성 조각 268개가 모두 앱 안(assets)에 포함되어
      있습니다 - 인터넷 연결 없이 동작합니다.


====================================================
6) 음성 파일 다시 녹음/교체하기
====================================================
특정 글자(예: '파')가 이상하게 들려서 새로 녹음하는 경우, 아래 순서대로
진행하면 됩니다. sync-sound-assets.bat 을 실행하는 것만으로는 안드로이드
앱에 반영되지 않습니다 - 빌드/설치까지 해야 폰에서 새 소리가 나옵니다.

1. 새로 녹음한 파일을 "Allinone (2)\sound\default\" 안의 같은 이름으로
   덮어씁니다. 예: 파 발음을 다시 녹음했다면
   "Allinone (2)\sound\default\pa.wav" 를 새 파일로 교체 (파일 이름은
   절대 바꾸면 안 됩니다 - 코드가 이 이름으로 찾습니다). 형식: 16비트
   PCM WAV. 샘플레이트나 모노/스테레오는 상관없습니다 (자동으로
   맞춰줍니다).

2. 데스크톱에서 먼저 귀로 확인합니다 (다시 빌드할 필요 없음, 파일만
   바꾸면 바로 반영됩니다):
       py tts.py 파
       py tts.py 법학
   이 단계에서 이미 원하는 소리가 나야 합니다. 여기서 이상하면 3번으로
   넘어가도 소용없으니 녹음을 다시 확인하세요.

3. c:\discordbot\sync-sound-assets.bat 을 실행합니다.
   이 스크립트가 하는 일은 딱 두 가지입니다:
     - py tts.py --check 로 빠진 파일이 없는지 확인
     - "Allinone (2)\sound" 전체를 이 프로젝트의
       app\src\main\assets\sound\ 에 복사(미러링)
   즉 안드로이드 프로젝트의 소스 코드 안에 새 파일을 가져다 놓는
   단계일 뿐이고, 아직 앱 자체는 업데이트되지 않은 상태입니다.

4. 안드로이드 앱을 다시 빌드하고 실제로 설치까지 해야 끝입니다:
     - 기기/에뮬레이터가 연결되어 있으면: Android Studio 에서 ▶(Run)
       버튼 한 번이면 새로 빌드해서 자동으로 재설치까지 됩니다 (가장
       간단한 방법).
     - 또는 .apk 를 직접 만들 때는: Build -> Build Bundle(s) / APK(s)
       -> Build APK(s) 로 새 app-debug.apk 를 만든 뒤, 그 파일을 폰에
       다시 설치합니다. 패키지/서명이 같은 디버그 빌드이므로 기존 앱을
       지우지 않고 그냥 덮어 설치(업데이트)하면 되고, 재생 속도/간격/
       볼륨 설정도 그대로 유지됩니다.

   3번(sync)만 하고 4번(재빌드+설치)을 건너뛰면 폰에는 여전히 예전
   음성 파일이 들어있는 예전 apk 가 그대로 남아 있어서 아무것도 바뀌지
   않은 것처럼 보입니다 - 흔한 실수이니 주의하세요.

파일 구성
====================================================
    app/src/main/java/kr/koreantts/app/
        KoreanPhonology.kt   korean_tts.py 의 발음 처리 로직 포팅
                            (연음화/비음화/유음화/격음화/경음화, 샘플 그룹핑)
        AudioEngine.kt       korean_tts.py 의 오디오 처리 로직 포팅
                            (WAV 로딩, 음량 보정, 크로스페이드, 받침 자르기)
        SpeechPlayer.kt      AudioTrack으로 재생하는 얇은 래퍼 (속도/볼륨 포함)
        Prefs.kt             앱 설정 저장 (속도, 띄어쓰기 간격, 볼륨, 받침 뒤 간격, 목소리)
        MainActivity.kt      독립 실행 화면 (텍스트 입력 -> 재생/저장, 설정 슬라이더 4종 + 목소리 드롭다운)
        ProcessTextActivity.kt  선택한 텍스트 읽기 (핵심 기능)
    app/src/main/assets/sound/default/  음성 조각 268개 (.wav) - 목소리별 하위 폴더

데스크톱 버전(korean_tts.py)과 로직을 동일하게 유지하려고 노력했습니다.
발음 규칙이나 음질 처리를 한쪽에서 고치면 다른 쪽도 같이 고쳐주세요.
