====================================================
새 목소리 녹음 도구 - VoiceRecorder.exe / voice_recorder.py
====================================================

새로운 목소리(성우)로 이 TTS를 쓰고 싶을 때, 필요한 268개(정확히는 실제로
쓰이는 253개) 음성 조각을 하나씩 녹음하도록 도와주는 프로그램입니다.
녹음이 끝나면 바로 기존 multi-voice 기능으로 쓸 수 있는 상태가 됩니다 -
따로 "TTS 목소리로 변환"하는 단계가 없습니다.

실행 방법
---------
    py voice_recorder.py         (파이썬으로 직접)
    VoiceRecorder.exe            (빌드된 실행 파일 - BUILD_EXE.txt 참고)

Windows 전용입니다 (마이크 녹음은 winmm.dll 을 ctypes 로 직접 호출합니다 -
pyaudio 등 추가 설치 없이). 다른 OS에서 실행하거나 마이크를 찾지 못하면
녹음 버튼만 꺼지고, 무엇을 녹음해야 하는지 목록/글자는 그대로 볼 수
있습니다.


사용법
------
1. 위쪽 드롭다운에서 이미 있는 목소리를 고르거나(원래 목소리인 default
   포함 - 특정 글자만 다시 녹음하고 싶을 때 유용합니다), 새 목소리
   이름을 직접 입력합니다 (영문/숫자, 예: narrator2 - 밑줄(_)이나
   마침표(.)로 시작하면 안 됩니다. 안드로이드가 그런 이름의 assets
   폴더를 자동으로 무시하기 때문입니다 - Allinone (2)\TTS_README.txt의
   "여러 목소리" 항목 참고).
2. "시작/이어하기"를 누릅니다. 이미 같은 이름으로 녹음하던 중이었다면
   자동으로 안 끝낸 부분부터 이어집니다 (완료된 항목은 왼쪽 목록에 ✔
   표시).
3. 화면 가운데 크게 뜨는 글자를 그대로 읽으면서 "● 녹음 시작"을 누르고,
   다 말하면 "■ 녹음 중지"를 누릅니다.
4. "▶ 들어보기"로 확인하고, 마음에 들면 "저장하고 다음"을 누릅니다.
   마음에 안 들면 그냥 다시 "● 녹음 시작"을 눌러 덮어쓰면 됩니다.
5. 253개를 전부 채울 때까지 반복합니다. 왼쪽 목록에서 아무 항목이나
   클릭해서 순서와 상관없이 이동할 수 있고, 나중에 특정 글자만 다시
   녹음하고 싶을 때도 그 항목을 클릭하면 됩니다.

화면 가운데 뜨는 글자가 실제로 녹음해야 하는 소리 그대로입니다 (예:
"ag" 조각이면 "악"이 뜹니다 - "악"이라고 말하고 녹음하면 됩니다). 받침
ㄴㄹㅁㅇ 은 원래 라이브러리와 같은 방식으로 "느/르/므/응" 미니 음절로
녹음합니다 (그래야 기존 CODA 관련 설정들과 어울립니다).


소리가 안 들릴 때
-----------------
녹음 후 뜨는 "녹음됨 (...초, 최고 음량 N/32767)" 표시를 먼저 확인하세요.

- 최고 음량이 300 미만이면(자동으로 ⚠ 경고가 같이 뜹니다) 마이크 소리가
  거의 안 잡힌 것입니다 - 재생이 안 되는 게 아니라 애초에 녹음된 내용이
  없는 것이니, 다음을 확인하세요:
    1. Windows 설정 -> 개인 정보 및 보안 -> 마이크 에서
       "마이크 액세스"와 "데스크톱 앱이 마이크에 액세스하도록 허용" 이
       모두 켜져 있는지 확인 (꺼져 있으면 이 프로그램뿐 아니라 대부분의
       녹음 프로그램이 무음만 녹음하게 됩니다).
    2. 설정 -> 시스템 -> 소리 에서 입력 장치가 실제 쓰려는 마이크로
       되어 있는지, 입력 볼륨이 0에 가깝지 않은지 확인.
    3. 마이크 자체의 음소거 스위치/버튼이 있다면 확인.
- 음량 수치는 정상으로 보이는데(예: 수천 이상) "들어보기"를 눌러도 아무
  소리가 안 나면, 화면에 "재생 실패: ..." 메시지가 뜨는지 확인하세요 -
  뜬다면 그 내용을 알려주시면 원인을 좁힐 수 있습니다. 참고로 재생은
  이 프로젝트의 다른 도구들(tts.py 등)과 완전히 같은 방식(winsound)을
  쓰므로, 그쪽에서 소리가 잘 난다면 이 도구의 재생 자체는 정상일
  가능성이 높습니다.

녹음 팁
-------
- 조용한 곳에서, 마이크와 일정한 거리를 유지하고 녹음하세요 (거리가
  들쭉날쭉하면 나중에 음량 자동 보정을 거쳐도 소리 크기가 고르지 않게
  들립니다).
- 한 조각당 너무 길게 끌지 말고, 그 글자만 자연스럽게 한 번 말하면
  충분합니다 (앞뒤에 약간의 무음은 자동으로 잘려나갑니다).
- 잘못 녹음했으면 그냥 같은 항목을 다시 녹음해서 덮어쓰면 됩니다 - 파일을
  직접 찾아 지울 필요 없습니다.


녹음이 끝나면
-------------
새 목소리는 sound\<이름>\ 에 바로 저장되므로, 이 폴더(Allinone (2))
안에서는 이미 완성된 상태입니다:

    py tts.py --voice <이름> 안녕하세요
    py tts.py --voice <이름> --check      (몇 개나 채워졌는지 확인)

데스크톱 앱(gui.py/KoreanTTS.exe)에서도 재생 탭의 목소리 드롭다운에 바로
나타납니다. Android 앱과 웹 버전에도 반영하려면 프로젝트 루트의
sync-sound-assets.bat 을 실행하세요 (Android는 추가로 재빌드도 필요합니다
- KoreanTTS-Android\README.txt 참고).

일부만 녹음하고 나머지는 비워둬도 괜찮습니다 - 없는 조각은 다른 목소리와
마찬가지로 "없음"으로 건너뛰고 나머지로 재생됩니다 (--check 로 몇 개가
비어있는지 확인 가능).


빌드된 exe를 다른 폴더/컴퓨터에서 쓸 때
----------------------------------------
VoiceRecorder.exe 는 실행 파일 바로 옆에 sound\ 폴더를 만들어 녹음을
저장합니다 (KoreanTTS.exe 가 sound_overrides.json 을 자기 옆에 저장하는
것과 같은 이유 - BUILD_EXE.txt 참고). 이 프로젝트 폴더 밖에서 녹음했다면,
끝난 뒤 그 sound\<이름>\ 폴더를 이 프로젝트의 Allinone (2)\sound\ 안으로
복사해 넣어야 실제로 쓸 수 있습니다.
