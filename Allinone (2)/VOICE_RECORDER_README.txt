====================================================
새 목소리 녹음 도구 - VoiceRecorder.exe / voice_recorder.py
====================================================

새로운 목소리(성우)로 이 TTS를 쓰고 싶을 때, 필요한 음성 조각(또는
음절)을 하나씩 녹음하도록 도와주는 프로그램입니다. 녹음이 끝나면 바로
기존 multi-voice 기능으로 쓸 수 있는 상태가 됩니다 - 따로 "TTS
목소리로 변환"하는 단계가 없습니다.

새 목소리를 만들 때 "새 목소리 만들기" 칸에서 녹음 완성도를 체크박스로
고를 수 있습니다. 자세한 내용은 TTS_README.txt의 "사운드 뱅크 설정"
항목 참고 - 요약하면:

  - "조각 방식"/"디폰"/"완전한 음절" 세 버튼은 예전처럼 서로 다른
    방식을 고르는 게 아니라, 아래 체크박스들을 한 번에 좋은 조합으로
    맞춰주는 프리셋일 뿐입니다 - 눌러놓고 다른 체크박스를 더 켜거나
    끌 수 있습니다.
  - 체크박스 목록: 자음+ㅢ 구분, 구개음화 뒤 반모음 구분(자/쟈 등),
    ㅐ/ㅔ 구분, ㅚ/ㅙ/ㅞ 구분, 온셋+중성·중성+받침 조각 별도 녹음,
    특정 음절 통째로 녹음. 각 체크박스 옆에 "(체크 시 총 N개)"로
    그걸 켜면 필요 개수가 몇 개가 되는지 바로 보여주고, 위쪽에는 지금
    조합대로면 총 몇 개를 녹음해야 하는지도 항상 보여줍니다.
  - 아무것도 안 켜면 기본 253개만 녹음하면 됩니다 (가장 빠름).
    "온셋+중성·중성+받침 조각 별도 녹음"을 켜면 그 위에 약 510개가
    더해지고(음절마다 최대 2개만 이어붙여서 조각 방식보다 자연스러움),
    "특정 음절 통째로 녹음"을 켜면 그 위에 실제로 쓰이는 한글 음절
    2,904개(발음 규칙으로 다른 음절에 항상 먼저 합쳐지는 것은 제외)가
    더해집니다(가장 자연스럽지만 가장 오래 걸림). 둘 다 켜거나 발음
    구분 설정을 더 켜면 그만큼 더 늘어납니다.
  - "빠진 음절 대체 목소리" 칸에서 이 목소리에 없는 조각/음절을 대신
    읽어줄 다른 목소리를 선택할 수 있습니다(선택 사항 - 이제 어떤
    조합에도 쓸 수 있어서, 기본 조각조차 다 채우지 않은 목소리도
    지정할 수 있습니다). 일부만 녹음하고 나머지는 대체 목소리로
    채우도록 만들 수 있어서, 자주 쓰는 것만 먼저 녹음해도 바로 쓸 수
    있습니다.

실행 방법
---------
    py voice_recorder.py         (파이썬으로 직접)
    VoiceRecorder.exe            (빌드된 실행 파일 - BUILD_EXE.txt 참고)

Windows 전용입니다 (마이크 녹음은 winmm.dll 을 ctypes 로 직접 호출합니다 -
pyaudio 등 추가 설치 없이). 다른 OS에서 실행하거나 마이크를 찾지 못하면
녹음 버튼만 꺼지고, 무엇을 녹음해야 하는지 목록/글자는 그대로 볼 수
있습니다.


사용법
------
1. 위쪽 드롭다운에서 이미 있는 목소리를 고르거나(원래 목소리인 default
   포함 - 특정 글자만 다시 녹음하고 싶을 때 유용합니다), 새 목소리
   이름을 직접 입력합니다 (영문/숫자, 예: narrator2 - 밑줄(_)이나
   마침표(.)로 시작하면 안 됩니다. 안드로이드가 그런 이름의 assets
   폴더를 자동으로 무시하기 때문입니다 - Allinone (2)\TTS_README.txt의
   "여러 목소리" 항목 참고).
2. "시작/이어하기"를 누릅니다.
   - 이미 있는 목소리면 바로 이어서 녹음할 수 있는 상태가 됩니다
     (완료된 항목은 왼쪽 목록에 ✔ 표시, 안 끝낸 부분부터 자동으로
     이어집니다).
   - 처음 만드는 이름이면 "새 목소리 만들기" 칸이 나타납니다. 프리셋
     버튼을 눌러 시작하거나 체크박스를 직접 골라 켠 뒤(옆 숫자로
     녹음량이 얼마나 늘어나는지 미리 확인할 수 있습니다), 필요하면
     대체 목소리도 고르고, "만들기"를 누르면 녹음이 시작됩니다. 한
     번 만든 뒤에는 개수/이름 규칙에 영향을 주는 설정(자음+ㅢ 구분,
     구개음화 뒤 반모음 구분, ㅐ/ㅔ 구분, ㅚ/ㅙ/ㅞ 구분)을 바꿀 수
     없으니(이미 녹음된 파일들이 그 설정 기준의 이름 규칙/개수를
     따르고 있어서) 신중하게 고르세요 ("온셋+중성·중성+받침 조각
     별도 녹음"/"특정 음절 통째로 녹음"은 개수에 제약이 없는 선택적
     설정이라 나중에도 특정 음절 다시 녹음 칸 등으로 사실상 켤 수
     있습니다).
3. 화면 가운데 크게 뜨는 글자를 그대로 읽으면서 "● 녹음 시작"을 누르고,
   다 말하면 "■ 녹음 중지"를 누릅니다.
4. "▶ 들어보기"로 확인하고, 마음에 들면 "저장하고 다음"을 누릅니다.
   마음에 안 들면 그냥 다시 "● 녹음 시작"을 눌러 덮어쓰면 됩니다.
5. 고른 조합만큼 채울 때까지 반복합니다 (위쪽 총 개수 표시 참고).
   왼쪽 목록에서 아무 항목이나 클릭해서 순서와 상관없이 이동할 수
   있고, 나중에 특정 글자만 다시 녹음하고 싶을 때도 그 항목을
   클릭하면 됩니다.

화면 가운데 뜨는 글자가 실제로 녹음해야 하는 소리 그대로입니다 (기본
조각에서 예: "ag" 조각이면 "악"이 뜹니다 - "악"이라고 말하고 녹음하면
됩니다. 온셋+중성·중성+받침/완전한 음절 조각이면 그 조각/음절 자체가
그대로 뜹니다). 받침 ㄴㄹㅁㅇ 은 기본 조각에서 원래 라이브러리와 같은
방식으로 "느/르/므/응" 미니 음절로 녹음합니다 (그래야 기존 CODA 관련
설정들과 어울립니다).

이미 만든 목소리를 열면 목록 아래에 "특정 음절 다시 녹음 (전체 대체)"
칸이 항상 나타납니다 - 재생해보고 특정 글자가 유독 어색하게 들릴 때,
그 글자 하나를 입력하고 위의 ● 녹음 시작/▶ 들어보기로 녹음한 뒤 이
칸의 "이 음절로 저장"을 누르면, 지금 목록에서 보고 있는 조각과
별개로 그 글자 전체를 통째로 대체하는 녹음이 저장됩니다 (처음
저장하는 순간 bank.json의 syllable_overrides 설정이 자동으로 켜집니다
- 직접 편집할 필요 없음).


다듬기 (파일 자체 편집)
-----------------------
화면 오른쪽의 "다듬기" 칸은 지금 왼쪽 목록에서 선택된 항목의 .wav
파일을 직접 편집합니다. 데스크톱 앱(gui.py/KoreanTTS.exe)의 "고급
설정" 탭과 비슷하지만 중요한 차이가 있습니다 - 그쪽은 sound_overrides.
json 에만 값을 적어 재생될 때만 적용하고 원본 파일은 그대로 두는
반면, 여기서는 "적용"/"정규화" 버튼을 누르면 실제 파일 내용이
바뀝니다.

  - 파형을 보면서 시작/끝 자르기 구간을 드래그하거나 슬라이더로
    조절하고, 음량 보정(dB)도 슬라이더로 조절합니다.
  - "▶ 적용 시 미리듣기"로 바뀔 소리를 먼저 들어보고, "▶ 저장된 파일
    그대로 듣기"로 지금 저장된 원래 소리와 비교할 수 있습니다.
  - "적용 (파일에 저장)"을 눌러야 슬라이더로 조절한 시작/끝 자르기와
    음량 보정이 실제로 .wav 파일에 저장됩니다 - 그 전까지는 슬라이더를
    아무리 움직여도 파일은 그대로입니다.
  - "정규화 (자동 음량 맞춤)"은 슬라이더와 별개로, 재생할 때마다
    자동으로 적용되는 것과 똑같은 음량 보정을 그 자리에서 파일에
    바로 구워 넣습니다 - 마이크 게인이 유독 낮았던 항목을 나중에
    한 번에 정리할 때 편리합니다.
  - 두 버튼 모두 처음 적용할 때 그 항목의 원본을 <이름>.orig 파일로
    자동 백업합니다(이미 백업이 있으면 다시 만들지 않음 - 항상 맨
    처음 원본을 보관). "되돌리기 (원본 복원)"를 누르면 언제든 그
    백업으로 되돌릴 수 있습니다. 이 .orig 파일은 sync-sound-assets.
    bat 이나 재생 어디에도 쓰이지 않는, 순수한 되돌리기용 백업입니다.
  - 같은 항목을 마이크로 다시 녹음해서 "저장하고 다음"(또는 "이
    음절로 저장")으로 덮어쓰면, 그 항목의 .orig 백업은 지워집니다 -
    새로 녹음한 소리가 새로운 "원본"이 되는 것이므로, 예전 녹음으로
    되돌아가지 않도록 하기 위함입니다.
  - 이음매 타이밍(교차 길이/받침 길이/받침 뒤 간격)처럼 파일 하나만
    으로는 결정할 수 없는 설정(옆 조각과 어떻게 이어붙는지에 관한
    것)은 여기 없습니다 - 그건 여전히 데스크톱 앱의 고급 설정 탭에서
    sound_overrides.json 으로 다룹니다.


소리가 안 들릴 때
-----------------
녹음 후 뜨는 "녹음됨 (...초, 최고 음량 N/32767)" 표시를 먼저 확인하세요.

- 최고 음량이 300 미만이면(자동으로 ⚠ 경고가 같이 뜹니다) 마이크 소리가
  거의 안 잡힌 것입니다 - 재생이 안 되는 게 아니라 애초에 녹음된 내용이
  없는 것이니, 다음을 확인하세요:
    1. Windows 설정 -> 개인 정보 및 보안 -> 마이크 에서
       "마이크 액세스"와 "데스크톱 앱이 마이크에 액세스하도록 허용" 이
       모두 켜져 있는지 확인 (꺼져 있으면 이 프로그램뿐 아니라 대부분의
       녹음 프로그램이 무음만 녹음하게 됩니다).
    2. 설정 -> 시스템 -> 소리 에서 입력 장치가 실제 쓰려는 마이크로
       되어 있는지, 입력 볼륨이 0에 가깝지 않은지 확인.
    3. 마이크 자체의 음소거 스위치/버튼이 있다면 확인.
- 음량 수치는 정상으로 보이는데(예: 수천 이상) "들어보기"를 눌러도 아무
  소리가 안 나면, 화면에 "재생 실패: ..." 메시지가 뜨는지 확인하세요 -
  뜬다면 그 내용을 알려주시면 원인을 좁힐 수 있습니다. 참고로 재생은
  이 프로젝트의 다른 도구들(tts.py 등)과 완전히 같은 방식(winsound)을
  쓰므로, 그쪽에서 소리가 잘 난다면 이 도구의 재생 자체는 정상일
  가능성이 높습니다.

녹음 팁
-------
- 조용한 곳에서, 마이크와 일정한 거리를 유지하고 녹음하세요 (거리가
  들쭉날쭉하면 나중에 음량 자동 보정을 거쳐도 소리 크기가 고르지 않게
  들립니다).
- 한 조각당 너무 길게 끌지 말고, 그 글자만 자연스럽게 한 번 말하면
  충분합니다 (앞뒤에 약간의 무음은 자동으로 잘려나갑니다).
- 잘못 녹음했으면 그냥 같은 항목을 다시 녹음해서 덮어쓰면 됩니다 - 파일을
  직접 찾아 지울 필요 없습니다.


녹음이 끝나면
-------------
새 목소리는 sound\<이름>\ 에 바로 저장되므로, 이 폴더(Allinone (2))
안에서는 이미 완성된 상태입니다:

    py tts.py --voice <이름> 안녕하세요
    py tts.py --voice <이름> --check      (몇 개나 채워졌는지 확인)

데스크톱 앱(gui.py/KoreanTTS.exe)에서도 재생 탭의 목소리 드롭다운에 바로
나타납니다. Android 앱과 웹 버전에도 반영하려면 프로젝트 루트의
sync-sound-assets.bat 을 실행하세요 (Android는 추가로 재빌드도 필요합니다
- KoreanTTS-Android\README.txt 참고).

일부만 녹음하고 나머지는 비워둬도 괜찮습니다 - 없는 조각은 다른 목소리와
마찬가지로 "없음"으로 건너뛰고 나머지로 재생됩니다 (--check 로 몇 개가
비어있는지 확인 가능).


빌드된 exe를 다른 폴더/컴퓨터에서 쓸 때
----------------------------------------
VoiceRecorder.exe 는 실행 파일 바로 옆에 sound\ 폴더를 만들어 녹음을
저장합니다 (KoreanTTS.exe 가 sound_overrides.json 을 자기 옆에 저장하는
것과 같은 이유 - BUILD_EXE.txt 참고). 이 프로젝트 폴더 밖에서 녹음했다면,
끝난 뒤 그 sound\<이름>\ 폴더를 이 프로젝트의 Allinone (2)\sound\ 안으로
복사해 넣어야 실제로 쓸 수 있습니다.
